WHAT YOU NEED TO DO
================================================================================

1. INSTALL NODE.JS (10 minutes)
   ---------------------------------
   On Ubuntu/Debian:
   
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   
   Verify:
   node --version  # Should show v20.x.x
   npm --version   # Should show 10.x.x

2. SETUP DATABASE (5 minutes)
   ---------------------------------
   Option A - Vercel Postgres (Easiest):
   - Go to vercel.com → Storage → Postgres
   - Create database → Copy connection string
   
   Option B - Supabase (Free):
   - Go to supabase.com → New Project
   - Settings → Database → Copy connection string
   
   Option C - Local PostgreSQL:
   sudo apt install postgresql postgresql-contrib
   sudo -u postgres psql
   CREATE DATABASE mobilepos;

3. CONFIGURE & RUN (5 minutes)
   ---------------------------------
   cd ~/Downloads/vercal/mobilepos
   
   # Edit .env with your database URL
   nano .env
   
   # Install and setup
   npm install
   npx prisma generate
   npx prisma migrate deploy
   npx prisma db seed
   
   # Start the app
   npm run dev
   
   # Open browser
   http://localhost:3000
   
   # Login
   Email: owner@mobilepos.com
   Password: password123
